# Updating the website (for club members)

No coding needed. Everything on the site is edited at **https://YOUR-DOMAIN/studio**.
Click **Publish** and the website updates within a few seconds.

---

## Log in

1. Open `YOUR-DOMAIN/studio` on a laptop or phone.
2. Sign in with the Google account (or email) the admin invited.
3. The menu on the left has: **Site settings, Events, Photo albums, Initiatives, Chapters, Team, Milestones, FAQ**.

> Not invited yet? Ask an admin: sanity.io/manage → your project → **Members** → **Invite** → role **Editor**.

---

## Events

### Add an event
1. **📅 Events** → the **✏️ Create** button at the top.
2. Fill in:

   | Field | What to type |
   |---|---|
   | Title | `RCB vs CSK Screening` |
   | Slug | Click **Generate** (it makes the web address) |
   | Start date & time | Pick date and time (Indian time) |
   | Venue | `Jayanagar community hall, Bengaluru` |
   | Google Maps link | Google Maps → Share → Copy link |
   | Chapter | Pick one, or leave empty for HQ / all chapters |
   | Type | Screening / Social Initiative / Fan Meet / Away Trip |
   | League | IPL / WPL / Off-season |
   | Opponent | Screenings only, e.g. `CSK` |
   | Cover image | Upload a photo **and type the Alt text** (describe the photo in a few words) |
   | Summary | One line shown on the event card |
   | Description | The full details |
   | RSVP link | A Google Form or ticket link (optional) |

3. **Publish** (green button, bottom right). It appears on Home and Events.

### Edit an event
**📅 Events** → click the event → change anything → **Publish**.

### Delete an event
**📅 Events** → click the event → **⋯** menu (bottom right, next to Publish) → **Delete** → confirm.
To hide it without deleting, use **⋯ → Unpublish**.

### After the event
Open it → **After the event** tab → add photos to **Gallery**, write a **Recap**, add **Impact numbers** (e.g. `Units of blood` · `120`) → **Publish**.
Events move from "Upcoming" to "Past" by themselves after their date.

## Team members

- **Add:** **👥 Team** → **Create** → Name, Photo (+ Alt text), Role, Chapter (empty = HQ), Instagram handle without `@`, Display order (smaller = first), turn on **Core team?** for HQ core team → **Publish**.
- **Edit:** click the person → change → **Publish**.
- **Remove:** click the person → **⋯ → Delete**. (If they lead a chapter, first pick a new lead in **📍 Chapters**.)
- **Make someone a chapter lead:** **📍 Chapters** → the chapter → **Lead** → pick the person → **Publish**.

---

## Photos

- **Add an album:** **🖼️ Photo albums** → Create → title, date, chapter, event → drag photos into **Items** (Alt text for each) → **Publish**. It shows in the Gallery and on the event page.
- **Remove a photo:** open the album (or event Gallery) → hover the photo → **⋯ → Remove** → **Publish**.
- **Change a cover or team photo:** open it → click the image → **Replace** (or **Remove**) → **Publish**.
- Use photos under 5 MB. Landscape for event covers, portrait for team photos.

## Everything else (⚙️ Site settings)

| What | Where in Site settings |
|---|---|
| Home page video | **Home page video** — upload an mp4 (muted, under 10 MB) |
| Trophy video | **Trophy video** — mp4 on a black background |
| Tagline, intro, stats (members, events, cities, years) | top of the page |
| "What we do" cards on Home | **What we do (pillars)** — the first one is shown large |
| Trophies (IPL/WPL years) | **RCB trophy cabinet** |
| Winning photos/videos | **Glory moments** |
| Recognition letter and badge | **Official recognition** |
| WhatsApp link, email, phone | near the bottom |

Also: **❓ FAQ**, **🏆 Milestones** (the About page timeline) and **❤️ Initiatives** work the same way: Create → fill → Publish.

---

## Tips

- **Alt text is required** on every photo. The Publish button stays disabled until you add it.
- Made a mistake? Open the item → **⋯ → Review changes** → pick an earlier version → **Restore**.
- Instagram posts appear on the site by themselves every hour. Nothing to do.
- Change not showing? Wait 30 seconds and refresh. Still nothing? Check you clicked **Publish**, not just closed the page.
