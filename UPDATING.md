# Updating the website (for club members)

No coding needed. Everything is edited at **https://YOUR-DOMAIN/studio**.
After you click **Publish**, the website updates within a few seconds.

---

## Log in

1. Go to `YOUR-DOMAIN/studio`.
2. Sign in with the Google account or email the admin invited.
3. You'll see a menu on the left: **Site settings, Events, Photo albums, Initiatives, Chapters, Team, Milestones, FAQ**.

> Not invited yet? Ask an admin to add you at sanity.io/manage → Members (role: **Editor**).

---

## Add an event

1. Click **📅 Events** in the left menu.
2. Click the **✏️ (Create)** button at the top.
3. Fill in the **Basics** tab:
   | Field | What to type |
   |---|---|
   | Title | e.g. `RCB vs CSK Screening` |
   | Slug | Click **Generate** (makes the web address) |
   | Start date & time | Pick date and time (IST) |
   | Venue | e.g. `PVR Orion Mall, Bengaluru` |
   | Google Maps link | Paste from Google Maps → Share |
   | Chapter | Pick the chapter, or leave empty for HQ |
   | Type | Screening / Social Initiative / Fan Meet / Away Trip |
   | League | IPL / WPL / Off-season |
   | Opponent | Only for screenings, e.g. `CSK` |
   | Cover image | Upload a photo **and fill in Alt text** (describe the photo) |
   | Summary | One line shown on cards |
   | Description | Full details |
   | RSVP link | Google Form / ticket link (optional) |
4. Click **Publish** (bottom right). ✅ Done. It appears on Home and Events.

**After the event:** open it again → **After the event** tab → upload photos to **Gallery**, write a **Recap**, add **Impact numbers** (e.g. `Units of blood` · `120`) → **Publish**.
The event moves to "Past events" by itself. You don't need to do anything.

---

## Add a team member

1. Click **👥 Team** → **✏️ Create**.
2. Fill in:
   - **Name**
   - **Photo** → upload a square-ish photo → fill **Alt text** (e.g. `Ravi smiling in RCB jersey`)
   - **Role** e.g. `Events Head` or `Kolar Chapter Lead`
   - **Chapter** → pick one (leave empty for HQ)
   - **Social links** → Instagram handle without `@`
   - **Display order** → smaller number shows first
   - **Core team?** → turn on for HQ core team (shown on About page)
3. **Publish**.

To make someone a chapter's lead: open **📍 Chapters** → the chapter → **Lead** → pick the person → **Publish**.

---

## Other common jobs

- **Photo album:** 🖼️ Photo albums → Create → title, chapter, event → drag photos into **Items** (fill Alt text for each) → Publish. Appears in Gallery.
- **Change stats / tagline / WhatsApp link / logo / recognition letter:** ⚙️ Site settings → edit → Publish.
- **FAQ:** ❓ FAQ → Create → question + answer → Publish.
- **Milestone on the About timeline:** 🏆 Milestones → Create → year, title → Publish.

## Tips

- **Alt text is required.** The Publish button stays disabled until you add it. It helps blind visitors and Google.
- Use photos under 5 MB. Landscape for event covers, portrait for team photos.
- Made a mistake? Open the document → **⋯ menu → Review changes** to restore an earlier version.
- Instagram posts appear automatically every hour. Nothing to do.
